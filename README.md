# PhaseForge / QFM Research

Complete available source and configurations, retaining three distinct experimental implementations.

| Folder | Role |
|---|---|
| qfmcnn | Earlier training, benchmarks, exports and diagrams |
| QFM_Research | Modular QFM-DCT implementation, run configurations and shape tests |
| robust-qfm | Robustness-oriented trainer and utility scripts |

These variants are preserved rather than merged. Checkpoints, CIFAR data and generated media are not bundled. Match the exact configuration and checkpoint before reproducing an experiment; no improvement is inferred from source alone. No quantum hardware execution is claimed.

Inspect imports before installing experiment dependencies; the supplied tree has no authoritative consolidated environment lock. The source uses PyTorch/torchvision and variant-specific scientific packages. Do not treat a newly guessed dependency list as the original environment.
